# 3m-bayonet-valve
Flow control valve compatible with the 3M Bayonet respirator filter connector. 

Due to needs of my own, I've made a set of flow control valves for the 3M Bayonet connector! 
These units snap into all 3m Bayonet system connections where filters would otherwise go. They
enable control over the amount of airflow moving across the bayonet connector and are *great* if
you have any needs involving controlling the respiratory flow of those to whom said respirators
are attached to :3
